ELEVOR360D — MOLLY AND THE LOST COLOURS OF MOONFLOWER WOOD
Version 1.0.0

A COMPLETE NEW STORYBOOK APP
Original fantasy adventure, approximately 10,000 words, 10 chapters and 50
numbered story pages. Full story, not a sample. Warm humour and talking-animal
adventure, with a beginning, a mystery and a complete ending. Six original
illustrations: a cover and five interior scenes. Includes a promotional banner.

Reader features: chapter navigation, direct page selection, next/previous,
multiple bookmarks, saved reading position, text-size controls and three themes.
Offline reading after the first successful online visit. Installation button
with browser-specific guidance. No account, payment or tracking required.

Pages scroll when needed on phones or with larger text. The cover is separate
from the 50 numbered pages. Progress and bookmarks belong to this device's
browser storage; clearing browser data removes them. They do not transfer
automatically to another device. Molly's progress is separate from the previous
Last Maintenance Window book, even when both are on the same website.

UPLOAD TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Create a NEW public repository, for example:
   Elevor360D-Molly-Moonflower-Wood
3. Upload the CONTENTS of the extracted folder, keeping the assets subfolder.
   index.html must be at the root, not inside another wrapping folder.
4. In Settings > Pages, choose Deploy from a branch, main, / (root), and Save.
5. Wait for GitHub to show its published HTTPS address.
6. Open the book online. Wait for Available offline, then test the reader.
7. Add that published address to your website's Books & Reading category as
   the free app opening URL. Suggested ID: molly-moonflower-wood

You can instead place ALL book files together in a NEW subfolder on an existing
HTTPS website. Do not replace the app store's index.html or service worker.
This book installs and caches within its own folder. No existing website files
are changed by this download.

INSTALL AND READ OFFLINE
Android: open the published page in Chrome and tap Install book. If there is
no automatic browser prompt, choose Install app / Add to Home screen from
Chrome's menu. iPhone/iPad: open in Safari > Share > Add to Home Screen.
Desktop Chrome/Edge: use the installation icon or browser menu.
The install button hides when the app is running in installed mode.

Open online once and wait for Available offline. Close the app, disconnect
from the internet and reopen it. The story and illustrations should load.
Do not use a directly opened computer file to test installation: service
workers and app installation need HTTPS hosting (localhost for development).

FILES TO EDIT
story.txt: full editable manuscript with page and chapter boundaries.
story.json and story-data.js: the same story prepared for the reader.
index.html, styles.css and app.js: the reader app.
assets/: illustrations and installation icons.
Molly_Moonflower_Wood_Banner.jpg: website image, 1672 x 941 pixels.
WEBSITE-LISTING.txt: ready-to-copy title, description and suggested app ID.
ART-NOTES.txt: illustration production notes.

UPDATES
After changes, update the version suffix of CACHE in sw.js, then upload all
changed files. An online visit installs the replacement cache. An additional
reload may be needed to display updated assets. Keep the same hosting path
if you want browser-local reading progress to remain in the same place.

FICTION AND ART
This is original fiction created for Elevor360D. Molly is a fictional magical
Yorkshire terrier. Rainbow fur, talking animals and the woodland are fantasy.
Original illustrations use the supplied character picture as visual inspiration
for rainbow hair, pink glasses and hippy accessories, with new compositions.
Illustrations are interpretations; minor visual details can vary.
No author identity has been invented. No advertisements or analytics are added
to interrupt the story. This is the same standalone book-reader format as the
previous app, in a new woodland colour theme.
